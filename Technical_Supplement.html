Data Isolation — RLS Architecture — డేటా వేర్పాటు
How RLS works — ఇది ఎలా పని చేస్తుంది
Every table has an app_id column identifying which MLA the row belongs to
On login, Supabase sets app.current_app_id in the session
Every SELECT/INSERT/UPDATE is filtered: USING (app_id = current_setting('app.current_app_id'))
Even if application code has a bug, the database engine itself blocks cross-tenant access
MLA-001 query physically cannot return MLA-002 rows — impossible at engine level
Tenant identification — అద్దెదారు గుర్తింపు
app_id — UUID assigned to each MLA/MP at registration time
Stored in apps table with constituency name, state, and contact
Loaded into React context on login — TenantContext.jsx
Passed to every Supabase query automatically — no manual filtering needed in UI code

Technical Q&A — సాధారణ సాంకేతిక ప్రశ్నలు
12 most common technical questions from MLA offices and IT departments
Q1. If one MLA's portal is hacked, can the attacker see other MLAs' data?
No. Data isolation is enforced at the PostgreSQL database engine level using Row Level Security (RLS). Even if an attacker gained full application access for MLA-001, the database physically blocks any query that tries to read MLA-002's rows. Application code is never trusted for isolation — the database itself enforces it.
లేదు. PostgreSQL RLS డేటాబేస్ ఇంజిన్ స్థాయిలో అమలవుతుంది. అప్లికేషన్ కోడ్ హ్యాక్ అయినా, డేటాబేస్ వేరే MLA డేటాను అందించదు.
Q2. What happens if the internet is down in the MLA office?
Citizens can still file complaints on mobile data. Staff dashboard requires internet but the React app is cached via Netlify CDN — it loads instantly even on slow connections. Complaint data syncs automatically when connection restores.
పౌరులు మొబైల్ డేటా ద్వారా ఫిర్యాదులు దాఖలు చేయవచ్చు. అప్లికేషన్ CDN ద్వారా కాష్ చేయబడుతుంది.
Q3. Can a citizen from MLA A's constituency file a complaint in MLA B's portal?
Each portal URL is unique to the MLA. When a citizen opens the URL, the app_id is embedded — complaints can only go to that specific MLA's database partition. There is no way for a citizen to accidentally reach the wrong MLA's portal through the shared URL system.
ప్రతి URL ఒక నిర్దిష్ట MLA కి మాత్రమే సంబంధించినది. తప్పు పోర్టల్‌కు పోవడం సాధ్యం కాదు.
Q4. How is the WhatsApp OTP system protected against fraud?
OTP is 6 digits, valid for 5 minutes only, single-use. Rate limited to 3 attempts per mobile number per hour via Supabase Edge Function. OTP is never stored in plaintext — only a bcrypt hash is kept. The Twilio WhatsApp Business API requires verified business registration.
OTP 5 నిమిషాలు మాత్రమే చెల్లుబాటు అవుతుంది, ఒకే ఉపయోగం, గంటకు 3 ప్రయత్నాలు మాత్రమే.
Q5. Where is the data physically stored? Is it in India?
Yes. Supabase database is hosted on AWS ap-south-1 (Mumbai). Netlify serves the frontend from Indian edge nodes for Indian users. No data leaves Indian jurisdiction. This complies with India's IT Act 2000 and aligns with the PDPB 2023 framework.
అవును. AWS Mumbai (ap-south-1) లో నిల్వ చేయబడుతుంది. భారతదేశంలోనే — IT చట్టం 2000 కు అనుగుణంగా.
Q6. How long does it take to add a new MLA to the system?
1 business day. MPower runs the onboarding wizard in the Control Panel: creates the app record, seeds geographic data (villages, mandals, constituencies), sets up RLS policies, generates the unique citizen portal URL, and sends WhatsApp credentials to the MLA office. No coding required per MLA.
1 పని దినం. Control Panel లో Onboarding Wizard అన్నీ స్వయంగా చేస్తుంది. ప్రతి MLAకి కోడింగ్ అవసరం లేదు.
Q7. Can the CM's office see individual citizens' personal details?
No. The CM office dashboard (planned) shows only aggregated statistics — total complaints per constituency, resolution rates, category breakdowns, pending counts. Individual citizen mobile numbers and complaint texts are never visible at state level. This is enforced by a separate read-only SQL view that strips PII before returning data.
లేదు. CM డాష్‌బోర్డ్ మొత్తం గణాంకాలు మాత్రమే చూపిస్తుంది. వ్యక్తిగత పౌర వివరాలు కనిపించవు — SQL view స్థాయిలో తొలగించబడతాయి.
Q8. What if MPower closes down — does the government lose all data?
No. The government can export the entire Supabase PostgreSQL database as a standard SQL dump at any time. The schema and all data are portable to any PostgreSQL-compatible hosting. We also provide monthly encrypted backups to a government-designated storage location on request.
లేదు. ప్రభుత్వం ఎప్పుడైనా PostgreSQL SQL dump ఎగుమతి చేయవచ్చు. డేటా ఎప్పుడూ ప్రభుత్వానికి చెందినదే.
Q9. Does the system work on basic Android phones with 2G/3G?
Yes. The citizen portal is a lightweight React app — initial load under 180KB gzipped. Tested on Android 8+ devices with 2G (EDGE) connections. WhatsApp OTP works on any network. Staff dashboard requires 3G or better for real-time updates.
అవును. పౌర పోర్టల్ 180KB కంటే తక్కువ. 2G నెట్‌వర్క్‌లో Android 8+ ఫోన్‌లలో పరీక్షించబడింది.
Q10. Is the source code auditable by the government?
Yes. Full source code access can be provided to an authorized government IT audit team under an NDA. The codebase is React + Node.js — standard, auditable, no obfuscation. We also provide a security audit report from an independent firm on request.
అవును. NDA కింద ప్రభుత్వ IT ఆడిట్ బృందానికి పూర్తి సోర్స్ కోడ్ అందుబాటు చేయవచ్చు.
Q11. How many concurrent users can the system handle?
Netlify CDN handles unlimited concurrent frontend users globally. Supabase free tier handles up to 500 concurrent database connections — sufficient for all 175 MLAs' offices simultaneously. If usage scales beyond free tier, Supabase Pro ($25/month) handles 10,000+ concurrent connections. MPower covers this cost.
175 MLAల కార్యాలయాలు ఒకేసారి వాడినా Supabase ఉచిత tier సరిపోతుంది. అదనపు ఖర్చు అయినా MPower భరిస్తుంది.
Q12. What is the Minister role and when will it be available?
PLANNED Minister view is designed but not yet built. It will show complaints categorized by department (irrigation, roads, health, education etc.) filtered to the Minister's assigned portfolio — reading only, no PII exposed. Timeline: 2 weeks after Mandapeta pilot confirms stable operation.
ప్లాన్ చేయబడింది — మండపేట పైలట్ స్థిరపడిన 2 వారాల తర్వాత నిర్మించబడుతుంది. మంత్రి వారి విభాగ గణాంకాలు మాత్రమే చూస్తారు.
